# Contribuindo com o Shipwright-PTBR

Contribuições são bem-vindas por **Pull Request**.

## Fluxo recomendado

1. Faça um fork do repositório.
2. Crie uma branch para sua alteração.
3. Faça commits pequenos e claros.
4. Teste a alteração localmente.
5. Abra um Pull Request para a branch `main`.
6. Descreva o que foi alterado e como foi testado.

## Branch principal

A branch `main` representa a versão oficial do projeto.

Não faça alterações diretamente na `main`. Mudanças devem passar por Pull Request e revisão antes do merge.

## Não envie

Nunca inclua em commits, Issues ou Pull Requests:

- ROMs;
- `oot.o2r` / `oot-mq.o2r`;
- arquivos `.env`;
- chaves da ElevenLabs ou outros tokens;
- saves pessoais;
- caches e builds locais;
- mods de terceiros já baixados sem autorização explícita de redistribuição.

## Reportando bugs

Ao abrir uma Issue, informe quando possível:

- versão do Shipwright-PTBR;
- versão/hash da ROM compatível utilizada, sem anexar a ROM;
- local/cena do jogo;
- personagem ou `textId`, se aplicável;
- print, vídeo curto ou trecho de log;
- passos para reproduzir o problema.

Para problemas do Ship of Harkinian original que não sejam causados por este fork, consulte o upstream:
https://github.com/HarbourMasters/Shipwright
