Zelda: Ocarina of Time dublado em português para PC

O Shipwright-PTBR reúne tradução de textos e dublagem em português do Brasil para The Legend of Zelda: Ocarina of Time, utilizando o port para PC Ship of Harkinian. Inclui integração com gráficos OoT Reloaded e modelos 3DS selecionados.

O que o projeto oferece

Uma versão para PC voltada aos jogadores brasileiros, com áudio, legendas e ajustes gráficos integrados ao Ship of Harkinian.

Dublagem PT-BR

Áudios em português brasileiro com seleção de vozes por personagem, incluindo tratamento de falas que compartilham IDs.

Textos traduzidos

2.163 mensagens revisadas e integradas ao jogo, abrangendo diálogos, narrativa, instruções e outros textos do jogo-base cobertos pelo projeto.

Melhorias gráficas

Instalação automatizada do OoT Reloaded 4K, opção de textura HD e modelos 3DS selecionados, além de ajustes de renderização.

Como instalar e jogar

O pacote público é disponibilizado no GitHub Releases. Não é necessário compilar o código para usar a versão Windows distribuída pelo projeto.

  1. Baixe a versão para Windows

    Use o botão de download acima ou consulte todas as versões.

  2. Extraia fora do OneDrive

    Por exemplo, em C:\Games\Shipwright-PTBR. Reserve espaço para os mods gráficos.

  3. Forneça sua ROM legal

    É necessário possuir uma cópia compatível de Ocarina of Time. O projeto não distribui ROMs.

  4. Execute o instalador

    Na primeira vez, abra INSTALAR_E_JOGAR_PTBR.bat. Para jogar depois, abra soh.exe.

Prefere gráficos mais leves? O perfil inicial é 4K, mas há instruções para trocar para HD no README do projeto.
