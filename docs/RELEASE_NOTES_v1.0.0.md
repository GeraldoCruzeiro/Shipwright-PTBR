# Shipwright-PTBR v1.0.0

Primeira release pública integrada do projeto.

## Destaques

- tradução PT-BR integrada ao Ship of Harkinian;
- revisão de 2.163 mensagens;
- runtime de dublagem PT-BR;
- pacote de vozes distribuído no ZIP oficial;
- tratamento de falantes e variantes para IDs compartilhados;
- preset gráfico final:
  - 60 FPS;
  - 125% de resolução interna;
  - MSAA 4x;
  - VSync;
  - LOD máximo;
  - distância de atores 2x;
  - itens/projéteis 3D;
  - suporte a backgrounds 3D;
- instalador automático do OoT Reloaded 4K/HD;
- integração seletiva com modelos 3DS de Link, NPCs, inimigos, animais, inventário, templos e backgrounds;
- inicializador `INSTALAR_E_JOGAR_PTBR.bat`.

## Instalação

1. Baixe `Shipwright-PTBR-v1.0.0-Windows-x64.zip`.
2. Extraia.
3. Forneça localmente uma ROM legal e compatível de Ocarina of Time.
4. Execute `INSTALAR_E_JOGAR_PTBR.bat`.

Na primeira execução, o perfil 4K baixa vários GB de conteúdo gráfico diretamente das fontes dos respectivos autores.

## Importante

A release não inclui ROM, `oot.o2r` ou `oot-mq.o2r`.

Leia `README.md`, `NOTICE.md` e `docs/PTBR_CREDITOS_E_DIREITOS.md` antes de redistribuir componentes deste projeto.
